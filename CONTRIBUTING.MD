# Contributing to NAU ENGINE


This page provides a guide for submitting issues, pull requests and reporting bugs for both [NauEngine](https://github.com/NauEngine/NauEnginePublic) and [NauEditor](https://github.com/NauEngine/NauEditorPublic). Thank you for taking your time to contribute to Nau Engine!

## I Have a Question

If you want to ask a question, first check the available [User Documentation](https://nauengine.org/docs/beta/user-doc/index.html).

If your question is not answered, visit our official [Telegram Community](https://t.me/nauenginecomm). 


## I Want To Contribute

You are welcome to contribute bug reports, issues and pull requests to [NauEngine](https://github.com/NauEngine/NauEnginePublic) and [NauEditor](https://github.com/NauEngine/NauEditorPublic)!

Please ensure you are sending your contribution to the appropriate repository. [NauEngine](https://github.com/NauEngine/NauEnginePublic) is dedicated to engine core, and [NauEditor](https://github.com/NauEngine/NauEditorPublic) is dedicated to the engine editor.


### Reporting Bugs

If you wish to report a bug, please ensure the following:

- You are using the latest version of the Engine.
- There is not already a bug report existing for your bug.

Create an issue in a respective GitHub repository. The issue should have a short, clear name describing the bug (for example, "Asset upload error"). Provide as much information regarding the bug as possible. This may include:

- Your exact input and output
- How can the bug be reproduced
- Your OS
- Screenshots, console logs 


### Submitting Pull Requests

If you wish to contribute to the source code, create a fork of the repository. Create a new branch for your changes. Ensure the issue you're working on isn't already in development.

Your contribution should follow the general codestyle of [NauEngine](https://github.com/NauEngine/NauEnginePublic/blob/main/doc/coding_style_guide.md) or [NauEditor](https://github.com/NauEngine/NauEditorPublic/blob/main/documents/code-style.md) respectively. 

Write code comments in Doxygen-compatible style.

Test your code before submitting pull requests.

Each pull request should solve ONE issue or add ONE new feature. Provide a detailed description for your contribution in the pull request. 


### Reporting Issues

If you have an problem or a suggestion that isn't categorized by any of the above, you may submit an issue in the respective repository. 

Ensure that the issue hasn't been adressed before. Provide a clear name and description for your issue.
